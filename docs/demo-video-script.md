# 轻语 TTS · 演示视频脚本（90 秒）

> 目标观众：**健身 / 通勤时想听自己资料的人**，不是开发者。
> 前 3 秒必须让人明白"这东西跟我有关"。

---

## 分镜

| 时间 | 画面 | 旁白 / 字幕 |
|---|---|---|
| 0:00–0:03 | 手机怼脸：跑步机上，耳机，一手扶栏杆 | 字幕：**"想听自己攒的资料，而不是听书 App 的书库"** |
| 0:03–0:12 | 电脑屏幕：粘贴一段《运动生理学 第3章》→ 选音色 → 点生成 | 旁白："把任何一段文字，粘进去。" |
| 0:12–0:20 | 进度条推进（显示"第 3 / 12 段"），快速剪辑 | 旁白："整章、整本书都行，它会自动分段。" |
| 0:20–0:28 | 光标插到句子中间，打上 `[停顿800]`，再生成 | 字幕：**可以手写停顿**　旁白："想让哪里停一下，就写一个停顿标记。" |
| 0:28–0:38 | 点"下载音频"，文件名叫《运动生理学 第3章.mp3》 | 旁白："下载下来，文件名就是你给资料起的名字。" |
| 0:38–0:48 | 手机文件管理器点击这个 mp3 → 锁屏 → 屏幕黑掉但声音继续 | 字幕：**锁屏继续放，不耗流量** |
| 0:48–0:56 | 切到"我的资料"，点"收听"，直接跳到上次听到的位置 | 旁白："下次点继续，从上次听到的地方开始。" |
| 0:56–1:08 | 拔掉网线 / 开飞行模式，重跑一次，提示"已使用本地语音引擎" | 字幕：**断网也能出音频**　旁白："网络不行？它有本地引擎兜底。" |
| 1:08–1:20 | 打开"离线朗读（手机本地语音）"，选系统音色开始读 | 旁白："连电脑都不用开，手机浏览器自己就能读。" |
| 1:20–1:30 | 回到跑步机镜头，耳机里在放 | 字幕：**轻语 —— 把你的资料变成可戴耳机听的声音**　（仓库地址） |

---

## 录制要点

1. **竖屏**（手机观看为主），1080×1920；
2. 全片不出现命令行（普通观众不看终端）；
3. 必须有一幕是"**下载到手机后用系统播放器锁屏播放**"——这是"离屏收听闭环"的证明，也是与"网页朗读器"的分水岭；
4. 删除测试用音频，避免录到无关文件名；
5. 结尾字幕放仓库地址 + 一句话安装方式（"电脑跑 `python app.py`，或直接下载单文件 HTML"）。
